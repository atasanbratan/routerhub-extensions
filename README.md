# RouterHub extension repository

Built and published by the [Publish workflow](https://github.com/atasanbratan/routerhub-extensions/actions/workflows/publish.yml)
from the `main` branch. Do not edit by hand.

- `index.json` / `index.min.json`: the list of extensions, with versions, API levels and checksums
- `apk/`: the signed APKs

Browse them at https://atasanbratan.github.io/routerhub/extensions/
